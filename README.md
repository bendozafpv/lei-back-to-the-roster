# Back to the Roster

Mobile-first Lei Wulong fan minigame for the campaign **#WeNeedLeiWulongBack**.

## Play

Open `index.html` in a browser. The complete V7 game and artwork are embedded in this one file and work offline after downloading it.

- Touch controls: **JUMP** and **ATTACK**.
- Keyboard: Space / Arrow Up to jump; J / X to attack.
- Jump over yellow barriers; attack crates, training dummies, drones, and street enemies.
- Choose a 1-, 2-, or 3-minute mission, collect Case Files, maintain your combo, and break the Roster Gate.

## GitHub Pages

In this repository, open **Settings → Pages**. Select **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.
